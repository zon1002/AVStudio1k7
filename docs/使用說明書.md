## 1. 簡介

AVStudio1k7 是個人用的 Windows 影片管理工具，**以片庫為中心**：你硬碟上的每一部影片都在同一份索引中，AV 資訊取得、NFO 編輯、重複清理、歸檔都操作這同一份片庫。

主要功能：

| 頁面 | 做什麼 |
|---|---|
| 📚 片庫 | 瀏覽、搜尋、篩選所有影片；直接編輯 NFO、換封面；海報牆、封面檢視、女優列表；更改檔名 |
| 🔍 AV 資訊 | 從 R18.dev / JavDB / Javbus 抓取影片資料，寫入 NFO 與封面 |
| 📋 待處理 | 抓取時無法自動決定的事項（衝突、封面取代、更名…）在這裡由你決定 |
| 🗂 歸檔 | 清理重複番號（移到資源回收桶）、把影片移到女優資料夾 |
| ⚙ 設定 | 片庫根目錄、AV 資訊、女優資料夾、外觀等所有設定 |

> 本版不提供下載功能。導覽列的「⬇ 下載」頁面保留顯示但不使用；設定頁中與下載相關的項目一律不勾選、變暗、不能更改（見第 10 章）。

幾個基本原則：

- **硬碟上的影片、`.nfo`、`.jpg` 才是真正的資料**；程式的資料庫只是索引，壞了可以重建。
- **NFO 格式與 AVTool 完全相同**，可以與 AVTool 交替使用。
- **不會永久刪除任何檔案**：清理重複只移到資源回收桶。
- **改檔名一定經過你確認**（「📋 待處理」或片庫的更名對話框）。
- **危險操作的確認對話框，預設按鈕一律是「取消」**（按 Enter 不會執行）。

### 1.1 與其他版本的關係

- **AVStudio1k7 是獨立的程式**：安裝名稱與 exe 是 `AVStudio1k7`，安裝在 `%LocalAppData%\Programs\AVStudio1k7`，資料在 `%AppData%\AVStudio1k7`、`%LocalAppData%\AVStudio1k7`。與 AVStudio 其他版本的資料夾、安裝記錄、單一執行鎖都不同，**可以同時安裝、同時開著**。視窗標題是「AVStudio1k7 2.0.1」。
- **不會匯入其他版本的任何資料**：設定、資料庫、待處理、抓取工作都不會帶過來，第一次啟動需要重新設定（見第 4 章）。其他版本的資料也不會被讀取或修改。
- 各版本共用的只有片庫硬碟上的影片、`.nfo`、`.jpg`。
- 建議不要讓兩個版本**同時**對同一個片庫做抓取、更名或整理（各自的索引與待處理看不到對方剛做的修改，會出現「已過期」或「檔案已變動」）。

## 2. 系統需求

| 項目 | 需求 | 說明 |
|---|---|---|
| 作業系統 | Windows 10 / 11（64 位元） | 不需要 .NET，也不需要 Visual C++ 可轉散發套件（執行階段已靜態連結） |
| Microsoft Edge | Javbus、Cloudflare 驗證備援需要 | Windows 10 / 11 內建；程式以自己的設定檔啟動 Edge，**不會使用或讀取你自己的 Edge 資料** |
| ffprobe | 選用 | 沒有時以內建方式讀取影片串流資訊；需要時自行放到程式目錄 `tools\` 或 PATH |
| 顯示 | 支援 OpenGL 的顯示卡驅動 | 無法使用 OpenGL 時自動改用 Direct3D 12 |
| 字型 | 微軟正黑體、Yu Gothic（或 Meiryo） | Windows 內建 |
| 網路 | 抓取 AV 資訊時需要 | 片庫瀏覽、NFO 編輯、更名、歸檔不需要網路 |

## 3. 安裝、更新與解除安裝

### 3.1 安裝

1. 執行 `AVStudio1k7_Setup_2.0.1.exe`。
2. 程式安裝到 **`%LocalAppData%\Programs\AVStudio1k7`**（例如 `C:\Users\你的帳號\AppData\Local\Programs\AVStudio1k7`），**不需要系統管理員權限**，整個安裝過程不會跳出 UAC。
3. 可選擇「建立桌面捷徑」（預設不勾）。開始功能表一定會建立捷徑「AVStudio1k7」。
4. 安裝完成時可勾選「啟動 AVStudio1k7」直接開啟。
5. 安裝程式沒有數位簽章，Windows SmartScreen 可能顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。

安裝程式只有一個主程式 `AVStudio1k7.exe`，不需要另外安裝 .NET、Visual C++ 可轉散發套件或其他瀏覽器元件；Microsoft Edge 是 Windows 內建的。

### 3.2 更新

- 直接執行新版安裝程式覆蓋安裝即可，設定、資料庫、片庫資料都保留；你自行放入 `tools\` 的 ffprobe 保留。
- AVStudio1k7 執行中時，安裝程式會提示先關閉。
- 第一次啟動新版時，資料庫會自動升級（只新增欄位 / 資料表，不會修改既有資料）。

### 3.3 解除安裝

- 從 Windows「設定 → 應用程式」解除安裝 AVStudio1k7。
- 會刪除程式資料夾與其中的 `tools\`（包含你自行放入的 ffprobe）。
- **不會刪除**：`%AppData%\AVStudio1k7`（設定、資料庫、log、Javbus 用的 Edge 設定檔）、`%LocalAppData%\AVStudio1k7`（縮圖等快取），以及你片庫中的任何影片 / NFO / 封面。要完全清除請手動刪除這些資料夾（見第 11 章）。
- 不影響其他版本 AVStudio 的安裝與資料。

> **⚠ 請在開始抓取、更名、歸檔之前，依序檢查下列項目。** 設定都在「⚙ 設定」頁，主要在「一般」「AV 設定」兩個分頁。設定修改後立即生效並儲存。

### 檢查清單

- [ ] 1. 片庫根目錄（一般）
- [ ] 2. 排除資料夾（一般）
- [ ] 3. 多人資料夾 / 無名女優資料夾（AV 設定）
- [ ] 4. ffprobe（一般；選用）
- [ ] 5. AV 資訊資料來源順序、Javbus Cookie / 驗證（AV 設定）

- [ ] 7. 外觀（一般）

### 4.1 片庫根目錄

**位置**：設定 → 一般 → 目錄 →「片庫根目錄」

| 項目 | 說明 |
|---|---|
| 作用 | 這些資料夾（含所有子資料夾）內的影片會列入片庫。 |
| 預設 | 空（第一次啟動不匯入任何舊設定，請自行新增）。 |
| 操作 | 「＋ 新增根目錄」加入；「移除」只是不再索引，**不會刪除任何檔案**（移除前會確認）。 |
| 何時修改 | 新增存放影片的磁碟 / 資料夾時。 |
| 設錯的後果 | 沒加入的資料夾，影片不會出現在片庫；加入太上層（例如整顆 `C:\`）會掃描大量無關檔案、變慢，並可能把程式碼專案中的 `.ts`（TypeScript）檔誤認為影片。 |

補充：

- 巢狀的根目錄會自動合併為外層（例如同時有 `E:\AV` 與 `E:\AV\新片`，只保留 `E:\AV`）。
- 外接硬碟拔除時，該根目錄標示「離線」、影片灰色顯示並保留在片庫中，接回後自動恢復，**不會被當成刪除**。
- 影片副檔名：`.mp4 .mkv .avi .wmv .mov .flv .ts .m4v .rmvb .rm .iso .webm`。
- 啟動時增量掃描（只讀取變動過的檔案），之後即時監看新增 / 改名 / 刪除；監看漏掉時會自動補掃。

> **⚠ 注意：根目錄清單是空的時候，片庫索引會被清空。** 啟動時的掃描與「🔄 重新掃描」以目前的根目錄清單為準：清單為空 → 片庫中所有影片從**索引**移除。只動索引，**不會刪除任何檔案**；加回根目錄後重新掃描即恢復（待處理等不受影響）。例外：啟動時設定檔讀取失敗的那次執行不會清除索引（見 11.3）。

### 4.2 排除資料夾

**位置**：設定 → 一般 → 目錄 →「排除資料夾」（片庫根目錄下方）

| 項目 | 說明 |
|---|---|
| 作用 | 被排除的資料夾不列入片庫（掃描與即時監看都跳過）。 |
| 預設 | 空。 |
| 兩種寫法 | **完整路徑**（按「瀏覽…」選）：該資料夾與其子資料夾不列入。**名稱**（輸入後按「加入」，例如 `node_modules`、`.git`）：任何根目錄下同名的資料夾都不列入（不分大小寫）。 |
| 何時修改 | 根目錄中有不是影片的資料夾（程式碼專案、網頁備份等），特別是含 `.ts` 檔的 `node_modules`——`.ts` 也是影片副檔名，會被誤認為影片，甚至被認出奇怪的番號（如 `ES-2015`）。 |
| 設錯的後果 | 排除了放影片的資料夾 → 那些影片從片庫消失（檔案仍在硬碟上，移除排除後就會回來）。 |

注意：

- 變更後會自動重新掃描；已在片庫中的影片從**索引**移除，**不會刪除檔案**。
- 名稱不可包含 `\` 或 `/`；名稱只比對根目錄**之下**的資料夾。
- 若選的路徑等於或包含某個片庫根目錄，會先跳確認對話框（預設按鈕為「取消」）。

### 4.3 多人資料夾 / 無名女優資料夾

**位置**：設定 → AV 設定 → 目錄 →「女優資料夾」：「多人資料夾」「無名女優資料夾」

| 設定 | 預設 | 用於 |
|---|---|---|
| 多人資料夾 | `Multiple` | 歸檔時，有多位女優的影片移到這裡 |
| 無名女優資料夾 | `Others` | 歸檔時，沒有女優（沒有 NFO，或 NFO 沒有女優）的影片移到這裡 |

兩種寫法：

- **名稱**（例如 `Multiple`）：放在「影片所在的根目錄」之下。非法字元會自動換成 `_`（例如輸入 `a/b` 會變成 `a_b`），清空則還原預設。
- **完整路徑**（按「瀏覽…」選）：固定資料夾，**必須位於某個片庫根目錄之內**。歸檔會移到這個資料夾，可以跨根目錄、跨磁碟。

設錯的後果 / 注意：

- 輸入片庫根目錄之外的完整路徑 → 欄位下方紅字「資料夾必須位於片庫根目錄之內（未儲存）」，維持原值。
- 之後若移除了包含它的根目錄（或把它加入排除），設定頁會顯示錯誤 / 警告；歸檔分頁受影響的影片不可勾選。**程式不會默默改放到別的地方**，請回設定頁修正。
- 硬碟上既有的舊資料夾（例如 `_多人`、`_無女優`）不會被搬動或改名；想沿用時，請自行在檔案總管改名，或把設定改成該名稱。

### 4.4 ffprobe

**位置**：設定 → 一般 → 其他 →「ffprobe（讀取串流資訊）」

- 作用：讀取影片解析度、編碼等（詳細面板「讀取串流資訊」、NFO 的 fileinfo）。**沒有 ffprobe 也可以**：程式內建讀取 mp4 / mkv / ts，並以 Windows 屬性補足其他格式。
- 預設：留空 = 自動尋找（程式目錄 `tools\`、PATH），找到時下方顯示「使用：路徑」。
- 指定路徑：輸入 `ffprobe.exe` 的完整路徑（例如 `C:\tools\ffprobe.exe`），離開欄位時寫入。
- 找不到時顯示「找不到 ffprobe（使用內建讀取）」，「讀取串流資訊」照常可用。

### 4.5 AV 資訊資料來源、Javbus

**位置**：設定 → AV 設定 → 其他 →「AV 資訊」

| 設定 | 預設 | 說明 |
|---|---|---|
| 資料來源（由上而下依序嘗試） | R18.dev → JavDB → Javbus，全部啟用 | 「↑」「↓」調整順序；取消勾選即停用。前面的來源仍缺日期 / 女優 / 封面時才查下一個。清單中標示「（找不到此來源）」的項目是本版沒有提供的來源，不會被使用，可取消勾選。 |
| Javbus Cookie | 空 | 在**自己的瀏覽器**開啟 javbus.com 後，從開發者工具複製 Cookie 貼上。程式不讀取你瀏覽器的資料（log 也不記錄 Cookie 內容）；無效的 Cookie 名稱會自動忽略。 |
| Javbus 使用背景（無頭）瀏覽器 | 勾選 | 一般不需更改。 |
| 開啟 Javbus 驗證 | — | 確認後開啟一個**可見的 Microsoft Edge 視窗**（使用程式自己的設定檔，不是你平常的 Edge），由你本人完成年齡驗證；完成後視窗自動關閉並通知「已通過驗證」；中途關掉視窗 =「未完成驗證」。 |

> **Javbus 年齡驗證必須由你本人完成。** 程式**不會**自動作答或繞過驗證；需要驗證時，該來源會被略過並在結果中提示。請用「開啟 Javbus 驗證」或貼上自己的 Cookie。

- 網站顯示 Cloudflare 驗證頁時，程式會以背景的 Edge 備援抓取（不會自動通過驗證）。
- 找不到 Edge 時顯示「找不到 Microsoft Edge，無法使用瀏覽器抓取（Javbus、Cloudflare 備援）。請安裝或修復 Microsoft Edge。」，其他來源照常。處理方式見第 13 章。

### 4.6 抓取規則預設值 / 快速模式

**位置**：設定 → AV 設定 → 其他 →「AV 資訊」→「規則預設值」；每批抓取前的規則對話框也可臨時修改（只影響該批，不會寫回設定）。

NFO 欄位**空白時一律直接填入**，規則只決定「已有值且不同」時怎麼做：

| 情況 | 選項（**預設**） |
|---|---|
| 發售日不同 | 保留舊值 ／ 採用新值 ／ **交給我決定** |
| 女優不同 | 保留舊值 ／ 合併（舊 + 新，去重，舊的在前） ／ 採用新值 ／ **交給我決定** |
| 其他欄位不同（標題、片商、廠牌、系列、導演、片長、類型） | **保留舊值** ／ 採用新值 |
| 沒有封面 | **自動下載** ／ 先確認 ／ 不下載 |
| 已有封面 | 不取代 ／ **相似度低於門檻才問** ／ 一律取代 |
| 相似度門檻（%） | **70** |
| 多筆搜尋結果（沒有相同番號時） | **交給我選擇** ／ 略過（有相同番號時自動採用） |
| 依標題更名（產生更名建議） | **不勾選** |

「相同」的比較方式：去頭尾空白；日期先正規化為 `yyyy-MM-dd`；女優 / 類型以集合比較（順序不同視為相同）。已有封面且相似度 ≥ 門檻視為同一張，不取代也不詢問。

「快速模式」一鍵帶入：

| 快速模式 | 日期不同 | 女優不同 | 其他欄位不同 | 沒有封面 | 已有封面 | 多筆搜尋結果 | 適合 |
|---|---|---|---|---|---|---|---|
| 填補缺失 | 保留 | 保留 | 保留 | 自動下載 | 不取代 | 交給我選擇 | 只補空白，不動已有資料與封面 |
| 全部覆蓋 | 採用新值 | 採用新值 | 採用新值 | 自動下載 | 一律取代 | 交給我選擇 | 以抓到的資料覆蓋全部欄位與封面 |
| 逐項決定 | 交給我決定 | 交給我決定 | 保留 | 自動下載 | 相似度低於門檻才問 | 交給我選擇 | 衝突都交給你在待處理頁決定（預設） |
| 自訂 | — | — | — | — | — | — | 手動改了任一項時自動顯示 |

- 「依標題更名」與「相似度門檻」不受快速模式影響。
- 「交給我決定 / 先確認 / 交給我選擇」的項目會進「📋 待處理」，抓取批次不會中斷或跳視窗。
- 設錯的後果：選「全部覆蓋」會用網路資料取代你手動修改過的標題 / 女優 / 封面（覆蓋前不再詢問）。

「抓取節奏」：每部間隔（秒）最小 **1**、最大 **2.5**（每部之間隨機等待，避免對網站送出太密集的請求）；重試次數 **3**（1–10）。數字欄在放開或離開欄位時才寫入。

- **底部狀態列**：根目錄與影片數、掃描進度、離線的磁碟。
- **通知**：右下角短暫顯示（儲存成功、掃描完成、錯誤等）；需要你決定的事才用對話框。
- 對話框都在主視窗內顯示（封面檢視視窗除外）。
- 主視窗大小與位置會記住，下次開啟時還原（螢幕配置改變、位置跑到畫面外時自動移回可見範圍）。

## 6. 📚 片庫

### 6.1 工具列

| 項目 | 說明 |
|---|---|
| ← 返回 | 回上一個檢視（也可用滑鼠「上一頁」鍵或 Alt+←）；有可返回的紀錄時才顯示 |
| 🎬 影片 / 👤 女優 | 切換影片模式與女優模式 |
| ▦ 海報牆 | 切換清單 ⇄ 海報牆 |
| 🔍 卡片大小 | 海報牆 / 女優模式才顯示：滑桿 50%–200%、「100%」還原；游標在卡片區時按住 Ctrl 捲動滾輪也可縮放 |
| 搜尋框 | 番號 / 標題 / 女優 / 片商；多個詞為「且」；全形空白也可分隔 |
| 篩選晶片 | 無 NFO、無封面、NFO 損毀、重複、無番號（顯示數量，可多選，多選為「且」） |
| 最新 / 最舊 | 依 NFO 發售日排序（新到舊 / 舊到新）；作用中的按鈕呈選取；沒有發售日的影片一律排最後 |
| 條件晶片 | 例如「女優：A ✕」「類型：X ✕」，每個條件一個晶片；按 ✕ 只移除該條件 |
| ✕ 清除篩選 | 一次清除搜尋、篩選晶片與全部條件 |
| 🔍 抓取資訊 | 對選取的影片抓取 AV 資訊（見第 7 章） |
| ⤓ 匯出 CSV | 匯出目前篩選結果（UTF-8 BOM，Excel 可直接開啟） |
| 🔄 重新掃描 | 重新增量掃描所有根目錄（整理執行中停用） |

搜尋規則：

- 不分大小寫、**不分全形 / 半形**（`ＳＳＩＳ` = `ssis`、`ﾏﾄﾞﾝﾅ` = `マドンナ`）；但平假名與片假名視為不同。
- 番號可不打連字號（`ssis001`）。
- `%`、`_` 照字面比對，不是萬用字元。

番號辨識（從檔名或 NFO 品番）：

- 一般番號：2–10 個英文字母 + 數字（例如 `SSIS-001`、`300MIUM-123`、`FC2-PPV-4343599`）。
- 單一字母番號：單一字母 + 3–6 位數字（例如 `n1850`、`k0123`），只在檔名中沒有一般番號時採用；`x264` / `x265` / `h264` / `h265` 不算番號。
- 日期形式的番號：月日年 6 位數字 + `_` 或 `-` + 2–3 位數字（例如 `100126_001`、`100126-001`、`100126_01`），照原樣顯示，`_` 與 `-` 視為不同的影片；前面帶片商英文字母時（例如 `pondo-101726_001`）整段是一個番號。

「重複」= 同番號（且同分段）的影片有兩部以上。`-CD1` / `-CD2`、`part1` / `part2`、`-1` / `-2`、成對的 `-A` / `-B` 是分段，不算重複；單獨的 `-C`、`-4K`、`_1080p`、`-2024` 則與無後綴版本算重複。

### 6.2 清單與海報牆

- 清單欄位：縮圖、番號、標題、女優、發售日、狀態；點欄位標題排序（再點一次反向）。
- 工具列「最新」「最舊」：依發售日排序，清單與海報牆都套用；**沒有發售日的影片不論最新或最舊一律排最後**。點欄位標題改用其他排序時，兩個按鈕的選取會取消（點「發售日」欄位標題等同最新 / 最舊，按鈕會跟著顯示）。
- 海報牆：封面格狀顯示。卡片大小可用工具列 🔍 滑桿或 Ctrl + 滾輪調整（50%–200%，每格 10%），與女優格共用、會記住；文字大小不變。放大後縮圖會在背景換成較清晰的版本。
- 兩種檢視共用同一份資料、篩選與選取；檢視模式、排序、篩選會記住。
- 片庫變動（新增、改名、抓取完成…）只更新受影響的列，**捲動位置不會跳**。
- 多選：Ctrl + 點擊、Shift + 點擊、Ctrl+A。
- 右鍵：開啟檔案位置、播放、複製番號、複製路徑、🔍 抓取資訊、✏ 更改名稱…、✏ 依 NFO 更名…（見 6.7）。
- 雙擊：清單模式 = 播放影片（使用 Windows 預設的播放程式）；海報牆 = 開啟封面檢視視窗。
- 離線磁碟上的影片灰色顯示，不能播放、更名或抓取。

### 6.3 封面檢視視窗

海報牆雙擊海報開啟（沒有封面時通知「沒有封面」，影片所在磁碟離線時也不開）。

| 操作 | 行為 |
|---|---|
| 開啟時 | 整張符合視窗、置中；小封面不放大超過 100% |
| 滑鼠滾輪 | 以游標為中心縮放（10%–800%） |
| 拖曳 | 圖片大於視窗時移動 |
| 「符合視窗」「100%」 | 切換顯示比例；工具列顯示目前百分比與圖片尺寸 |
| 雙擊圖片 | 播放影片並關閉封面視窗；播放程式關閉後 AVStudio1k7 自動回到前景（無法播放時視窗保持開啟） |
| Esc | 關閉 |

每次雙擊開一個新視窗；視窗大小與位置會記住。封面視窗屬於主視窗：一直顯示在主視窗之上，主視窗最小化時一起隱藏、還原時一起出現；工作列上仍各有按鈕。

### 6.4 影片 / 女優切換

- 「👤 女優」：女優卡片格，每張顯示代表封面（該女優最新且有封面的影片；都沒有封面顯示「👤」）、名稱、部數。
- 可「搜尋女優名稱」；「依部數」（預設，多 → 少）/「依名稱」排序。
- 名稱前後空白、大小寫、全形 / 半形不同視為同一位。女優一律取自 NFO。
- 點卡片（或 Enter）→ 回到影片模式，條件晶片「女優：X」，只列出她的影片（已有女優條件時換成她；類型 / 片商條件保留）。

### 6.5 詳細面板（NFO 直接編輯）

選一部影片，右側顯示詳細面板：

- 上方：封面、「🖼 換封面」「▶ 播放」「📂 位置」「🔍 重新抓取」「✏ 更名」（見 6.7）。
- 欄位：品番、標題、日期、片商、女優（標籤，輸入後按 Enter 新增、× 移除）、類型（標籤）；展開「更多（廠牌 / 系列 / 導演 / 片長 / 串流資訊）」。標籤太多時自動換行；名稱比一行還長的標籤以「…」截斷，滑鼠移上去顯示完整名稱。
- 面板左邊緣可以拖曳調整寬度，內容不會撐住面板，可以一路拖到最窄。
- 修改過的欄位橘框；「💾 儲存 (Ctrl+S)」「↶ 還原 (Esc)」。只寫入改過的欄位，其他內容（含 fileinfo）保留。
- 驗證：日期必須是 `yyyy-MM-dd`、片長必須是整數（分鐘）；錯誤欄位紅框、不可儲存。
- 沒有 NFO 的影片：直接填寫後儲存即新建 NFO。
- 有未儲存的修改時切換影片、跳轉或關閉程式 → 詢問「儲存 / 不儲存 / 取消」。
- NFO 被其他程式在你編輯期間改過 → 儲存時詢問重新載入或覆蓋。
- NFO 損毀時唯讀顯示原始內容，不提供編輯（避免資料遺失）。
- 換封面：選 jpg / png / webp，轉存為影片同名 `.jpg`；已有封面時先確認覆蓋。
- 「讀取串流資訊」把解析度、編碼等填入，儲存後寫入 NFO（沒有 ffprobe 時使用內建讀取）。
- 多選時顯示「已選 N 部」，不提供編輯。
- 「🔍 重新抓取」以這部的番號（片庫索引的番號；沒有時用檔名）抓取 AV 資訊，先顯示規則對話框（見 7.2）。

**點欄位列出相關影片**：點女優或類型標籤、或片商右側「🔍」→ 片庫列出相關影片（條件晶片「女優：X」「類型：Y」「片商：Z」）。比對為完全相同（「三上」不會列出「三上悠亞」），使用已儲存的值。條件可與搜尋、篩選晶片、排序同時使用。

**條件疊加**：女優、類型、片商條件可以同時使用，全部符合才列出；每種類最多一個。例如先點女優 A、再點類型 X → 列出「女優 A 且類型 X」的影片；接著點女優 B → 女優條件換成 B，類型 X 保留。工具列依女優、類型、片商順序每個條件顯示一個晶片，✕ 只移除該條件；「✕ 清除篩選」一次清除全部。跳轉時會清除影片搜尋文字，篩選晶片、排序與其他條件保留。

### 6.6 ← 返回

- 從女優卡片、欄位點擊跳轉後，可按「← 返回」、滑鼠上一頁鍵或 Alt+← 回到前一個檢視；模式、檢視、整組條件、搜尋、篩選、排序、選取、捲動位置都還原，最多 20 步。加入的條件與目前完全相同時不會新增返回紀錄。
- 切到其他導覽頁、按條件晶片 ✕、「✕ 清除篩選」、或從 AV 資訊頁定位影片時，返回紀錄會清空。

### 6.7 更改名稱 / 依 NFO 更名

只改**檔名**：不移動到其他資料夾（資料夾由歸檔決定），也不修改 NFO 內容。更名一律由你確認，程式不會自動改檔名。

**更改名稱（單部）**

- 入口：選取 1 部影片 → 右鍵「✏ 更改名稱…」，或詳細面板的「✏ 更名」（詳細面板有未儲存的 NFO 修改時，先詢問儲存 / 不儲存 / 取消；取消就不開對話框）。
- 對話框：顯示目前檔名；新檔名輸入框預填**建議名稱**「番號 標題 女優」（取自 NFO 的品番、標題、女優，標題會去掉重複的番號與結尾女優名；NFO 沒有品番時從檔名辨識番號；沒有 NFO、NFO 損毀、或沒有標題也沒有女優時沒有建議，預填目前檔名），副檔名固定顯示在輸入框後方；「套用建議」可隨時還原成建議名稱。
- 檔名過長時只截短標題，仍過長才從最後一位女優開始移除；**番號一定保留**。
- 「一起改名」清單列出同主檔名的附屬檔（`.nfo`、`.jpg`、字幕等）；影片與附屬檔一起改名，任一失敗全部還原；附屬檔的目標名稱已存在時不改任何檔。
- 即時錯誤（紅字，「更名」按鈕停用）：檔名空白、含 `\ / : * ? " < > |`、以點或空白結尾、Windows 保留名稱、路徑過長、「名稱沒有變更」、「目標已存在」。只改大小寫（例如 `abc-123.mp4` → `ABC-123.mp4`）視為同一個檔案，可以更名。
- 更名成功：對話框關閉、通知「已更名」，片庫清單選取新檔名；片庫索引與待處理項目的路徑同步更新。失敗（檔案被鎖等）時留在對話框顯示原因。
- 限制：影片必須位於片庫根目錄內；**離線的影片、整理（重複清理 / 歸檔 / 批次更名）執行中不能更名**（右鍵選單與「✏ 更名」按鈕停用）。正在抓取 AV 資訊的影片入口仍可用，按「更名」時對話框顯示「此影片正在抓取 AV 資訊，請稍後再試」。片庫正在完整掃描時，對話框會等掃描完成才開啟。

**依 NFO 更名…（批次）**

- 入口：選取 1 部以上影片 → 右鍵「✏ 依 NFO 更名…」。詳細面板有未儲存的修改時，先詢問「儲存 / 不儲存 / 取消」（取消 = 不開預覽）。
- 預覽清單每部一列：勾選、目前檔名、**建議檔名（可直接編輯）**、狀態。建議名稱的規則同上。
- 不勾選並註明原因：沒有 NFO、NFO 損毀、沒有番號、名稱已相同、目標已存在、與同批其他影片的新名稱重複、離線、正在抓取。編輯檔名後立即重新驗證（包含同批重複）。
- 「更名 N 部」依序執行，可隨時「取消」（已完成的保留）；執行期間整理（歸檔頁的「🗑 移到資源回收桶…」「📦 歸檔選取…」）與片庫重新掃描停用。結束顯示「已更名 X、失敗 Y」，失敗列顯示原因、可修改後再試；完成後片庫選取第一部更名的影片。

**待處理的「更名建議」**：抓取 AV 資訊產生的更名建議使用同一套「番號 標題 女優」規則。在待處理按「更名」同樣會同步片庫索引；新檔名與目前相同時視為已套用。

## 7. 🔍 AV 資訊

在片庫多選影片 →「🔍 抓取資訊」（工具列 / 右鍵），或詳細面板「🔍 重新抓取」單部。批次不跳視窗：能依規則決定的直接寫入 NFO（格式與 AVTool 相同）與同名 `.jpg`，無法決定的放進「📋 待處理」。

### 7.1 工作區

AV 資訊頁直接列出片庫影片，用來整理 NFO 與封面：

- 欄位：勾選、番號、標題、女優、NFO（✓ / ✗ / 損毀）、封面（✓ / ✗）、路徑、抓取狀態、🔍。
- 搜尋（番號 / 標題 / 女優）與篩選「無封面」「無 NFO」「重複」（可同時開啟，為「且」；不影響片庫頁的篩選）。工作區的搜尋與篩選不會保存，下次開啟恢復預設。
- 「全選」「全不選」；「🔍 抓取 NFO（選取 N 部）」批次抓取；每列「🔍」只抓這一部。
- 雙擊列 → 跳到片庫頁並選取該部。
- 離線根目錄的影片顯示但不可抓取。
- 抓取狀態：等待 / 處理中 / 完成 / 待處理 / 需選擇 / 查無 / 錯誤 / 已取消。

在片庫頁選取影片按「🔍 抓取資訊」，或在詳細面板按「🔍 重新抓取」，效果相同。抓取使用的番號 = 片庫索引記錄的番號（沒有時用檔名）。

### 7.2 規則對話框

每次抓取前顯示本批規則（帶入設定的預設值），可選快速模式或逐項修改，**只影響這一批**，不會改變設定的預設值。規則說明見 4.6。要改預設值請到 設定 → AV 設定 →「規則預設值」。

### 7.3 抓取佇列

頁面下方「抓取佇列」可收合：

- 進度「第 N / M 部・預估剩餘」、本批規則摘要、每部結果（番號、結果、來源、狀態）。
- 「⏸ 暫停」「▶ 繼續」「⏹ 中斷」（等待中的取消，處理中的停止）：佇列執行中才可使用，閒置時停用。
- 雙擊佇列中的工作：「待處理」/「需選擇」→ 跳到「📋 待處理」頁並捲到該部影片；其他狀態 → 跳到片庫頁並選取該部。
- 「🧹 清除已完成」：移除完成、查無、錯誤、已取消的工作。「待處理」/「需選擇」的工作要先到「📋 待處理」頁確認或略過，處理完會自動變成「完成」，再按此鈕移除。
- 一次處理一部，每部之間隨機等待（見 4.6「抓取節奏」）。
- 佇列存在資料庫中：關閉程式時還有未完成的工作 → 下次啟動詢問是否「繼續抓取」。
- 查詢結果：能依規則決定的直接寫入 NFO 與同名 `.jpg`；其他的進「📋 待處理」。所有來源都查無時不寫任何檔案（狀態「查無」）。
- **網路逾時**算該來源的錯誤（來源欄顯示「來源:錯誤：連線逾時」），工作依其他來源的結果結束；只有按「⏹ 中斷」才是「已取消」。

### 7.4 單筆查詢

「🔎 單筆查詢…」：

1. 輸入番號 →「查詢」。
2. 預覽抓到的欄位與封面（不會寫入任何檔案）。
3. 片庫有同番號的影片時可按「寫入到片庫中的影片…」；多部同番號時勾選要寫入哪幾部。
4. 顯示規則對話框 → 排入抓取佇列。

## 8. 📋 待處理

抓取時無法依規則自動決定的事，全部集中在這裡，導覽列徽章顯示數量。依影片分組，可逐筆或整批決定。

| 類型 | 內容 | 單筆操作 |
|---|---|---|
| 選擇搜尋結果 | 候選清單（縮圖、番號、標題、來源） | 選這個 ／ 略過 |
| 日期衝突 | 目前值、新值、來源 | 保留 ／ 採用新值 |
| 女優衝突 | 舊名單、新名單 | 保留 ／ 合併 ／ 採用新值 |
| 封面取代 | 舊圖、新圖、相似度、尺寸 | 保留舊圖 ／ 換新圖 |
| 新封面確認 | 新圖、來源 | 下載 ／ 不要 |
| 更名建議 | 舊檔名 → 新檔名（可編輯）、連同更名的附屬檔 | 更名 ／ 不更名 |

- 上方類型篩選：全部、選擇結果、日期、女優、封面、更名（顯示數量）。篩選不會保存。
- 頁面的「整批採用」「整批保留」作用於目前篩選顯示的項目（先確認數量）；「整批合併」只在篩選「女優」時可用。**整批操作一律不處理「選擇搜尋結果」**，這類一定由你逐筆選。
- 每組有「這部全部採用」「這部全部保留」（「這部全部保留」會略過該部的搜尋結果選擇）。
- 「選擇搜尋結果」選定後，該部重新排入抓取佇列，可能再產生其他項目。
- **已過期**：項目建立後影片或 NFO 又被修改，顯示「⚠ 已過期（影片或 NFO 在建立後被修改）」，只能「捨棄」或「重新抓取」。
- 套用失敗（檔案被鎖等）時項目保留並顯示錯誤，可再試。
- **更名**：影片與同主檔名的 `.nfo`、`.jpg`、字幕一起改名，任一失敗則全部還原；目標檔名已存在時不允許。程式不會在其他地方自動改檔名。

## 9. 🗂 歸檔

歸檔頁有「重複清理」「歸檔」兩個分頁。第一次切入時載入，之後按「🔄 重新整理」才重新載入。

### 9.1 安全規則（兩個分頁共通）

> - **只移到資源回收桶，絕不永久刪除。** 任何可能導致永久刪除的情況一律不處理。
> - 只回收**本機固定磁碟**上的檔案（外接 / 隨身碟 / 網路磁碟沒有資源回收桶，一律不回收）。
> - 路徑經過**連結（junction / 符號連結）或資料夾掛載點**的檔案一律不回收（那些位置可能在網路 / 卸除式磁碟上，Windows 會直接永久刪除），原因「路徑經過連結或掛載點，無法確認資源回收桶，為避免永久刪除而不處理：（路徑）」，檔案留在原處。磁碟類型與資源回收桶設定以**檔案實際所在的磁碟區**判斷。
> - 檔案大於該磁碟資源回收桶容量、或整批累計超過容量、或該磁碟設為「不要將檔案移到資源回收桶」→ 該部略過，檔案留在原處。
> - 執行前每一部都重新檢查：檔案大小、修改時間與畫面載入時相同，否則略過「檔案已變動」。
> - 正在抓取或有待處理項目的影片不會被處理。
> - 確認對話框的預設按鈕是「取消」（按 Enter 不會執行）。
> - 可隨時「⏹ 停止」（目前這部完成後停止）；完成後顯示摘要；每筆操作寫入 log（`[Organize]`）。
> - 執行中片庫「🔄 重新掃描」、右鍵「✏ 更改名稱…」/「✏ 依 NFO 更名…」、詳細面板「✏ 更名」停用；「🔄 重新整理」、篩選、搜尋、勾選照常可用。執行中再按執行按鈕會通知「整理執行中，請稍後再試」。
> - **執行中關閉主視窗**：視窗不會立即關閉，通知「整理執行中：這部完成後自動關閉」；目前這部做完後程式自動關閉（不顯示摘要），已處理的保留、其餘未動。

**附屬檔**：與影片同資料夾、檔名以影片主檔名開頭並接 `.副檔名`（`.nfo`、`.jpg`、`.zh.srt`…）或 `-poster`、`-fanart`、`-thumb`、`-landscape`、`-banner`、`-clearart`、`-clearlogo`、`-disc` 的檔案，會跟影片一起處理。**共用附屬檔保護**：同資料夾有 `X.mp4` 與 `X.mkv` 共用 `X.nfo` 時，只處理其中一部的話 `X.nfo` / `X.jpg` 留在原處。

**選擇會保留**：兩個分頁的勾選 / 保留選擇與目前顯示的清單無關，被篩選或搜尋隱藏再顯示時還原；**被篩選 / 搜尋隱藏的項目不計入摘要、也不會被處理**。「全選」只勾可處理的列。

### 9.2 重複清理

- 同番號（且同分段）的影片分組。群組標題列：勾選「處理此組」、番號、部數。
- 成員列：「保留」單選、路徑、大小、修改日期、NFO ✓/✗、封面 ✓/✗、附屬檔、狀態。雙擊在檔案總管顯示（無法開啟時通知「無法開啟檔案位置」）。
- 預設保留：NFO + 封面最完整 → 檔案最大 → 最新 → 路徑。可逐組改選。
- 根目錄篩選：群組內任一部在該根目錄即顯示。切換篩選不會重設你的選擇。
- 底部摘要「回收 N 部 · X GB · 附屬檔 M 個」→「🗑 移到資源回收桶…」。確認文字在合計超過資源回收桶容量時另外提示。
- 不可回收的成員顯示原因（此磁碟沒有資源回收桶 / 離線 / 抓取中 / 有待處理項目），仍可被選為保留；整組沒有可回收的檔時顯示「（沒有可回收的檔案）」。
- 執行時若同組「保留」的檔案已不存在，其他成員略過（不會把一組全部回收）。
- 回收的檔案可從 Windows 資源回收桶還原，還原後片庫自動出現。

### 9.3 歸檔

把影片移到女優資料夾：

- 列出條件：有番號、但不在目的地資料夾（已在目的地資料夾或其更深子資料夾的不列出，資料夾名稱大小寫不同也算已歸檔）。NFO 損毀的影片不列入（無法判斷女優），工具列提示「另有 N 部 NFO 損毀，未列入」；沒有番號的影片不列入。
- 目的地：1 位女優 = `根目錄\女優名稱`；多位 = 多人資料夾；**沒有女優（沒有 NFO，或 NFO 沒有女優）= 無名女優資料夾**（預設 `Others`）。多人 / 無名女優資料夾可為名稱或完整路徑，見 4.3。
- 沒有女優的列：女優欄顯示「（無女優）」；沒有 NFO 的列狀態加註「沒有 NFO」（仍可勾選）。之後抓到女優時，這部會在歸檔分頁顯示為「在其他資料夾」（預設不勾），需要時勾選即可移到女優資料夾。
- 欄位：勾選、番號、女優、目前位置、→ 移到、狀態；「目前位置」「→ 移到」可點擊開啟資料夾：「目前位置」的檔案已不在時顯示「找不到檔案（可能已移動或根目錄離線）：…」；「→ 移到」的資料夾尚未建立時開啟最近一層存在的上層並提示「資料夾尚未建立，已開啟上層：…」（不會建立資料夾）。
- 預設勾選：根目錄最上層的影片；在其他子資料夾的列出但不勾（「在其他資料夾」）。「全選」不會勾**沒有 NFO 且在其他子資料夾**的列（避免把既有資料夾中的影片整批移到無名女優資料夾），需要時請個別勾選。
- 不可勾選：目的地已有同名影片或同名附屬檔、或同批兩部會移到同一路徑（「目的地已有同名檔，請先清理重複」）；離線；抓取中；多人 / 無名女優資料夾設定已不在片庫根目錄內。
- 搜尋（番號 / 標題 / 女優；沒有 NFO 的影片只比對番號 / 標題）、根目錄篩選、「全選」「全不選」→「📦 歸檔選取…」。確認對話框顯示部數與附屬檔數；含沒有 NFO 的影片時另列「其中 X 部沒有 NFO，將移到無名女優資料夾（Y 部目前在其他子資料夾）」。
- 歸檔分頁載入後才抓到 NFO 的影片（原本「沒有 NFO」），執行時略過「檔案已變動」，請重新整理後再歸檔。
- 影片與附屬檔一起移動、檔名不變；**不會覆蓋目的地的任何檔案**；跨磁碟時先複製再刪除來源。任一步失敗 → 已移動的移回原處（「移動失敗，已還原：…」），只刪除這次建立的資料夾。
- 移走後原資料夾若完全空了（含隱藏檔也沒有）會自動刪除，往上直到根目錄為止（根目錄保留）。
- 片庫索引的路徑同步更新。

### 11.1 備份

- **真正需要備份的是片庫中的影片、`.nfo`、`.jpg`**——這些是唯一真實的資料。
- 想保留設定：備份 `settings.json`。
- 想保留待處理項目與抓取紀錄：程式關閉時備份 `avstudio.db`。

### 11.2 重設

- **資料庫（索引）有問題**：關閉程式，把 `avstudio.db` 改名（例如 `avstudio.db.old`）再啟動，程式會建立新資料庫並重新掃描所有根目錄。片庫內容會從硬碟上的影片 / NFO / 封面完整重建；待處理項目、抓取紀錄會重新開始。
- **資料庫毀損時程式會自動處理**：改名為 `avstudio.db.bad` 後重建（見第 13 章）。
- **設定檔毀損**（內容不是正確的設定格式）：自動改名為 `settings.json.bad`，以預設值啟動。
- **完全重設**：關閉程式後刪除 `%AppData%\AVStudio1k7` 與 `%LocalAppData%\AVStudio1k7`。下次啟動視為第一次使用。片庫中的檔案不受影響。

### 11.3 設定檔讀取失敗時

`settings.json` 存在但**讀不到**（例如被其他程式鎖住、沒有權限）時，程式以預設值啟動，為了不讓預設值覆蓋你的設定檔，**這次執行完全不儲存設定**，並且：

- 設定頁顯示「⚠ 啟動時無法讀取設定檔…」提示；修改設定不會寫入檔案。
- 啟動掃描與「🔄 重新掃描」不會清除片庫索引中的任何影片（log「設定檔讀取失敗，重新掃描不清除索引」）。
- log 會記錄原因。關閉程式、排除原因（例如關閉鎖住檔案的程式）後再開即可恢復正常。

## 12. 同時只能開一份

AVStudio1k7 同一時間只能執行一份。已經開著時再從開始功能表或捷徑啟動，不會出現第二個視窗，而是把原本的視窗（含最小化的）帶到前面；Windows 不允許搶前景時改為工作列閃爍。程式是以「同一個 exe 檔名（`AVStudio1k7.exe`）且使用同一個資料資料夾」找原本的視窗，所以從不同資料夾的複本、短檔名路徑或 `subst` 磁碟代號啟動也一樣。

原因：兩份程式同時使用同一個資料庫，啟動檢查可能把使用中的資料庫誤判為毀損而改名重建。執行安裝程式時若 AVStudio1k7 開著，也會提示先關閉。

- 只限 AVStudio1k7 自己：AVStudio 的其他版本是不同的程式，可以同時開著（各自的資料庫）。

關閉主視窗時，程式依序處理：未儲存的 NFO 修改確認 → 儲存視窗位置與設定 → 結束抓取佇列（處理中的工作改回「等待」，下次啟動詢問是否繼續）→ 關閉背景的 Edge → 結束。

## 13. 常見問題 / 疑難排解

**Q：Javbus 一直被略過 / 提示需要驗證？**
Javbus 有年齡驗證，程式不會自動作答或繞過。請到 設定 → AV 設定 →「開啟 Javbus 驗證」，在跳出的 Edge 視窗中自己完成；或從自己的瀏覽器複製 Cookie 貼到「Javbus Cookie」。其他來源不受影響。

**Q：Javbus 或 Cloudflare 備援回報「找不到 Microsoft Edge…」？**
Microsoft Edge 沒有安裝或已損壞。請安裝 Microsoft Edge，或在 Windows「設定 → 應用程式 → 已安裝的應用程式 → Microsoft Edge → 修改 → 修復」。其他來源照常。

**Q：抓取結果「查無」？**
所有啟用的來源都找不到這個番號。請確認片庫認出的番號正確（片庫清單的「番號」欄；檔名中有多個像番號的字串時可能認錯，可先更改檔名）；也可用「🔎 單筆查詢…」換個寫法試試。

**Q：抓取結果「錯誤：連線逾時」？**
該來源網路逾時，工作會依其他來源的結果結束。稍後對這部再按「🔍」重新抓取即可。

**Q：AV 設定的資料來源清單出現「（找不到此來源）」？**
那是本版沒有提供的來源，不會被使用。取消勾選或不理會都可以。

**Q：設定頁有些項目是灰色、不能改？**
那些是下載相關的設定，本版已取消下載功能，所以一律停用（見第 10 章）。

**Q：片庫部數突然變少 / 變多？**
最常見的原因：
- 加入或移除了「排除資料夾」（變更後會重新掃描，被排除的影片從片庫移除，但檔案仍在）。
- 外接硬碟離線（影片會灰色顯示、仍計入，接回後恢復）。
- 根目錄中有 `node_modules` 之類含 `.ts` 檔的資料夾被當成影片 → 用排除資料夾排除。
- 新增 / 移除了片庫根目錄。**根目錄清單被清空時，片庫索引會被清空**（檔案不受影響；加回根目錄重新掃描即恢復，見 4.1）。

狀態列會顯示目前根目錄、影片數與離線磁碟。

**Q：啟動後 log 出現「資料庫毀損，改名為 .bad 後重建」？**
程式偵測到 `avstudio.db` 毀損，已改名為 `avstudio.db.bad` 並重新掃描建立索引。片庫內容（來自硬碟上的影片 / NFO / 封面）會完整恢復；抓取紀錄、待處理會重新開始。`.bad` 檔可刪除。

**Q：設定頁顯示「⚠ 啟動時無法讀取設定檔…」？**
`settings.json` 啟動時讀不到（常見原因是被其他程式鎖住，例如同步軟體或編輯器）。這次執行不會儲存任何設定、也不會清除片庫索引。請關閉程式、排除原因後再開（見 11.3）。

**Q：待處理項目顯示「已過期」？**
項目建立後，影片或 NFO 又被修改了（例如你在詳細面板編輯過、或用其他程式改過）。為避免覆蓋新的內容，只能「捨棄」或「重新抓取」。

**Q：深色模式下有文字看不清楚？**
可先在 設定 → 一般 →「外觀」切到淺色，並回報該畫面。

**Q：「重複」把 CD1 / CD2 算成重複？**
分段影片（`-CD1`、`part2`、`-1` / `-2`、成對的 `-A` / `-B`）不算重複；單獨的 `-C` 會與無後綴版本算重複（通常是字幕版），`-4K`、`_1080p`、`-2024` 也與無後綴版本算重複。

**Q：清理重複時某部顯示「此磁碟沒有資源回收桶」或「超過資源回收桶容量」？**
程式只回收到資源回收桶、絕不永久刪除。外接 / 網路磁碟沒有回收桶；超過容量的檔案 Windows 會直接永久刪除，所以程式拒絕處理。請自行在檔案總管處理，或分批處理。

**Q：回收時顯示「路徑經過連結或掛載點…」？**
該檔案是經由 junction、符號連結或資料夾掛載點出現在片庫中的，實際位置可能在沒有資源回收桶的磁碟上。為避免永久刪除，程式不處理；請在檔案總管直接到檔案實際所在的位置處理。

**Q：歸檔時某部不能勾選？**
看該列的狀態說明：目的地已有同名檔（請先清理重複）、離線、正在抓取，或多人 / 無名女優資料夾的完整路徑已不在片庫根目錄內（回設定頁修正，見 4.3）。

**Q：更名時顯示「此影片正在抓取 AV 資訊，請稍後再試」？**
等 AV 資訊頁的抓取佇列處理完這部再更名。

**Q：AVStudio1k7 與其他版本的 AVStudio、AVTool 可以一起用嗎？**
可以。AVStudio1k7 不讀取、也不修改它們的任何設定與資料（共用的只有片庫中的影片 / NFO / 封面）。只是不建議同時對同一個片庫抓取、更名或整理（見 1.1）。

**Q：問題回報要附什麼？**
`%AppData%\AVStudio1k7\logs\` 中當天的 log 檔。
