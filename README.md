# AVStudio1k7 閹割版

**版本：2.0.1**

> 📖 文件：[使用說明書](docs/使用說明書.md)（**第一次使用前請先看第 4 章「必須設定 / 檢查的項目」**）・[下載安裝檔（Releases）](https://github.com/zon1002/AVStudio1k7/releases)

個人用的 Windows 影片工具，以 AVStudio Rust 版 2.0.0（AVStudio 1.4.0 C# / WPF 的 Rust 完整重寫，egui）為基礎的**閹割版：取消下載功能**。以片庫為中心：硬碟上的每一部影片都在同一份索引中，AV 資訊取得、重複清理、歸檔都操作這同一份片庫。

## 下載與安裝

1. 到 [Releases](https://github.com/zon1002/AVStudio1k7/releases) 下載最新版的 `AVStudio1k7_Setup_<版本>.exe`。
2. 執行安裝檔：安裝到 `%LocalAppData%\Programs\AVStudio1k7`，**不需要系統管理員權限**。安裝檔沒有數位簽章，Windows SmartScreen 若顯示「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」。
3. 第一次啟動後到「⚙ 設定」新增片庫根目錄，詳見 [使用說明書](docs/使用說明書.md) 第 4 章。

更新：直接執行新版安裝檔覆蓋安裝，設定與資料都保留。解除安裝：Windows「設定 → 應用程式」。

## 與原版的差異

- **沒有下載功能**：主視窗「⬇ 下載」分頁保留顯示，但不會下載任何影片（加入、確認、佇列、續傳都不會開始下載；確認時顯示「此版本已取消下載功能」）。
- 設定頁的下載相關項目全部**不勾選、變暗、不能更改**：「一般 → 下載」卡片（含「啟動時自動續傳未完成的下載」「監看剪貼簿」）、「AV 設定 → 下載與抓取」卡片、「下載來源」分頁。
- 安裝檔只有主程式 `AVStudio1k7.exe`：不附下載來源 plugin 與下載工具。
- **獨立的程式**：程式名稱 / 安裝名稱 `AVStudio1k7`（exe `AVStudio1k7.exe`），安裝在 `%LocalAppData%\Programs\AVStudio1k7`，資料在 `%AppData%\AVStudio1k7`、`%LocalAppData%\AVStudio1k7`。與原版 AVStudio Rust 版（AVStudioRS）及 C# 版的資料夾、單一執行鎖、安裝記錄都不同，**可以同時安裝、同時執行**。視窗標題「AVStudio1k7 2.0.1」。
- **不匯入其他版本的任何資料**：設定、資料庫、待處理、抓取工作都不會帶過來。第一次啟動是全新狀態，需要重新設定片庫根目錄等。
- **共用的只有片庫硬碟上的影片 / `.nfo` / `.jpg`**：NFO 格式與 AVTool / C# 版逐 byte 相同，可以交替使用。
- 建議不要讓兩個版本**同時**對同一個片庫做抓取、更名或整理：各版本的索引與待處理各自記錄，看不到對方剛做的寫入，會出現「已過期」或「檔案已變動」。

## 功能

### 📚 片庫

- 多個根目錄（巢狀自動合併）、啟動增量掃描、即時監看新增 / 改名 / 刪除、外接磁碟離線時保留記錄（灰色顯示，接回自動恢復）；排除資料夾（完整路徑或名稱，例如 `node_modules`）。
- 清單 ⇄ 海報牆、🎬 影片 / 👤 女優列表（代表封面、部數，可搜尋 / 依部數或名稱排序）；海報牆與女優格卡片縮放 50%–200%（🔍 滑桿或 Ctrl + 滾輪，縮圖 480px、依實際像素解碼）。
- 搜尋（番號 / 標題 / 女優 / 片商；不分大小寫、不分全形 / 半形，平假名與片假名不同；`%`、`_` 照字面）、篩選晶片（無 NFO、無封面、NFO 損毀、重複、無番號）、排序、最新 / 最舊（沒有發售日的一律排最後）、CSV 匯出。
- 女優 / 類型 / 片商條件可疊加（每種類一個，全部符合才列出）；詳細面板點女優 / 類型、片商 🔍 跳轉；「← 返回」（滑鼠上一頁鍵、Alt+←）還原前一個檢視，最多 20 步。
- 右側詳細面板直接編輯 NFO（格式與 AVTool 相同；只寫改過的欄位）、換封面、讀取串流資訊（內建讀取 mp4 / mkv / ts；有 ffprobe 時使用 ffprobe）。
- 封面檢視視窗：海報牆雙擊海報開啟，滾輪以游標為中心縮放（10%–800%）、拖曳、符合視窗 / 100%；雙擊圖片播放影片，播放程式關閉後 AVStudio1k7 回到前景；視窗大小 / 位置會記住，隨主視窗最小化 / 還原、保持在主視窗之上。
- 「重複」以番號 + 分段判斷：`-CD1` / `-CD2`、`part1` / `part2`、`-1` / `-2`、成對的 `-A` / `-B` 是分段；單獨的 `-C`、`-4K`、`_1080p`、`-2024` 與無後綴版本算重複。
- 更改名稱（單部）與依 NFO 批次更名：檔名「番號 標題 女優」，附屬檔（`.nfo`、`.jpg`、字幕）一起改名，任一失敗全部還原；更名一律由你確認。

### 🔍 AV 資訊

在片庫多選影片 →「🔍 抓取資訊」（工具列 / 右鍵），詳細面板可「🔍 重新抓取」單部；AV 資訊頁是整理 NFO 的工作區（列出片庫影片、搜尋與「無封面 / 無 NFO / 重複」篩選、勾選後批次抓取、每列 🔍 單部抓取、🔎 單筆查詢）。批次不跳視窗：能依規則決定的直接寫入 NFO（格式與 AVTool 相同）與同名 `.jpg`，無法決定的放進「📋 待處理」。

- 抓取佇列存資料庫：一次處理 1 部、每部之間隨機等待、暫停 / 繼續 / 中斷；關閉程式時未完成的工作下次啟動詢問是否繼續。網路逾時算該來源錯誤，工作依其他來源結束（只有按「⏹ 中斷」才是「已取消」）。
- 資料來源與順序：R18.dev → JavDB → Javbus（設定頁可調整順序 / 停用）；前面來源仍缺日期 / 女優 / 封面時才查下一個。
- Javbus 年齡驗證：程式**不會**自動作答或繞過。需要驗證時略過並提示；請在設定頁「開啟 Javbus 驗證」開啟的可見 Microsoft Edge 視窗中由自己完成，或貼上自己的 Cookie。
- Javbus 與 Cloudflare 驗證頁的備援抓取使用 Windows 內建的 **Microsoft Edge**（程式自己的設定檔，不使用你平常的 Edge 資料）；不需要另外安裝瀏覽器元件。

**抓取規則**（設定頁預設，每批可臨時修改）：

| 情況 | 選項（**預設**） |
|---|---|
| NFO 欄位空白 | 一律直接填入 |
| 發售日不同 | 保留舊值 ／ 採用新值 ／ **交給我決定** |
| 女優不同 | 保留舊值 ／ 合併（舊 + 新，去重，舊的在前） ／ 採用新值 ／ **交給我決定** |
| 其他欄位不同（標題、片商、廠牌、系列、導演、片長、類型） | **保留舊值** ／ 採用新值 |
| 沒有封面 | **自動下載** ／ 先確認 ／ 不下載 |
| 已有封面 | 不取代 ／ **相似度低於門檻才問**（預設 70%） ／ 一律取代 |
| 多筆搜尋結果 | 有相同番號自動採用；沒有相同番號：**交給我選擇** ／ 略過 |
| 依標題更名 | **關閉** ／ 開啟（標題與檔名不同時產生更名建議） |

### 📋 待處理

導覽列「📋 待處理」顯示未處理數量。依影片分組，可逐筆或整批決定：選擇搜尋結果、日期衝突、女優衝突、封面取代、新封面確認、更名建議。

- 整批操作不會套用到「選擇搜尋結果」項目，這類一定由你逐筆選擇。
- 過期偵測：項目建立後影片或 NFO 又被修改，標示「已過期」，只能捨棄或重新抓取。
- 套用失敗（檔案被鎖等）項目保留並顯示錯誤，可重試。
- 更名一定經此確認（或片庫的更名對話框）：影片與同主檔名的 `.nfo`、`.jpg`、字幕一起改名，任一失敗則還原；目標已存在則不允許。
- AV 資訊抓取佇列雙擊「待處理」/「需選擇」的工作 → 跳到待處理頁並捲到該部影片。

### ⬇ 下載（已取消）

導覽列「⬇ 下載」分頁保留顯示，但本版**不會下載任何影片**：輸入框加入、待確認「✔ 確認選取並下載」、佇列的繼續 / 重試、啟動時續傳都不會開始下載；「剪貼簿監看」不勾選、變暗。

### 🗂 歸檔

- **重複清理**：同番號（且同分段）的影片分組；預設保留「NFO + 封面最完整 → 檔案最大 → 最新」的那部，可逐組改選；其餘連同附屬檔（`.nfo`、`.jpg`、字幕、`-poster.jpg` 等）移到資源回收桶（可還原）。外接 / 網路磁碟、離線、抓取中或有待處理項目的檔案不會被回收。檔案大於資源回收桶容量、整批累計超過容量、或該磁碟設為直接刪除時一律不處理（**絕不永久刪除**）。路徑經過連結（junction / 符號連結）或資料夾掛載點的檔案也一律不回收；磁碟類型與資源回收桶設定以檔案實際所在的磁碟區判斷。
- **歸檔**：有番號、但不在女優資料夾的影片，移到同一根目錄下的女優資料夾（1 人 = 女優名稱、多人 = 多人資料夾、沒有 NFO / NFO 沒有女優 = 無名女優資料夾 `Others`）；根目錄最上層的影片預設勾選；目的地已有同名檔時擋下；移走後空的原資料夾自動刪除。多人 / 無名女優資料夾設為完整路徑時，影片移到該資料夾（可跨根目錄 / 跨磁碟）。
- 兩個動作都可停止（這部完成後停止）、完成後顯示摘要；執行中片庫「重新掃描」與更名停用；執行中關閉主視窗 → 等目前這部完成後自動關閉。每筆操作寫入 log（`[Organize]`）。

### ⚙ 設定

三個分頁「一般」「AV 設定」「下載來源」（各分頁目錄設定在前），標題列右側與主視窗標題顯示「AVStudio1k7 2.0.1」。外觀：跟隨系統 / 淺色 / 深色。設定修改後立即生效並儲存；關閉主視窗時，設定頁尚未離開欄位的輸入也會寫入。啟動時設定檔讀取失敗（例如被其他程式鎖住）時，該次執行使用預設值、**不儲存任何設定**，設定頁顯示提示。下載相關的項目全部停用（見「與原版的差異」）。

## 系統需求

- Windows 10 / 11（64 位元）。**不需要 .NET，也不需要 Visual C++ 可轉散發套件**（執行階段已靜態連結）。
- Microsoft Edge（Windows 內建）：Javbus 與 Cloudflare 驗證備援使用。
- 顯示：以 OpenGL 繪製；顯示卡驅動無法使用 OpenGL 時自動改用 Direct3D 12。
- 字型：微軟正黑體、Yu Gothic（沒有時用 Meiryo），Windows 內建。
- 選用：ffprobe（讀取串流資訊；沒有時使用內建讀取）。

效能（原版 M6 驗收，1 萬部片庫、200% 顯示比例，Intel i7-14700K / RTX 4080 SUPER）：冷啟動到可操作約 0.54 秒、海報牆捲動 0% 掉格、閒置私人記憶體約 86 MB。

## 資料位置

- `%AppData%\AVStudio1k7\`：`settings.json`、`avstudio.db`（索引，可重建）、`logs\`、`browser-profile\`（Javbus 用的 Edge 設定檔）
- `%LocalAppData%\AVStudio1k7\`：`thumbs\w480\`（縮圖快取）、`pending\`（待處理的新封面暫存）、`browser-temp\`（Cloudflare 備援暫存，下次啟動清除）
- 程式目錄（預設 `%LocalAppData%\Programs\AVStudio1k7\`）：`AVStudio1k7.exe`

與原版 AVStudioRS、C# 版 AVStudio 的資料夾完全分開。
